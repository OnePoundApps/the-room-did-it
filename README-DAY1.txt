THE ROOM DID IT — DAY 1 SETUP (5 steps)
=======================================

WHAT THIS IS
Your first real XR code. On your Quest 3S it starts a passthrough AR
session, scans your room, finds a table-height surface, and drops a
floating yellow evidence marker on it. Pinch your fingers near it to
"collect" it. That's the core mechanic of the whole game.

FOLDER CONTENTS
  index.html   -> the page (loads three.js from the internet)
  main.js      -> the game code

SETUP
1. Copy these two files INTO your repo folder (the one GitHub Desktop
   opens). Let them REPLACE the old index.html - the old "coming soon"
   file is deleted automatically by replacing it. Nothing else on your
   PC needs deleting.
2. Open that folder in VS Code (File -> Open Folder).
3. In GitHub Desktop: you'll see 2 changed files. Summary:
   "day 1: AR evidence marker" -> Commit to main -> Push origin.
4. Wait 1 minute, then on your Quest 3S open the browser and go to:
   https://YOUR-USERNAME.github.io/the-room-did-it/
5. Tap ENTER THE CRIME SCENE. Look at a table. The yellow marker appears.
   Reach out and pinch your thumb+finger near it.

TIPS
- Make sure your Quest has done Settings -> Physical Space -> Space Setup
  (scan your room) or plane detection finds nothing.
- If the page is blank/black: hard-refresh (reload button in Quest browser).
- Tell your AI partner EXACTLY what you see (or send a photo) each time,
  especially any error text at the top of the screen.
